# doomscroll-detector
A python AI wrapper for Gemma 4 to detect doomscrolling!

# Why?
I want to fix my bad habit of procrastination lol

# Usage
You need to set a GEMINI_API_KEY global env variable as your real Gemini api key. Then just run the python wrapper!

⚠️ PLEASE USE THIS IN A VENV

If you get dependency errors just run:
```
pip install google-genai opencv-python pyttsx3
```
